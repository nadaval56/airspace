# מגבלות מרחב אווירי — מטה בנימין

אתר סטטי אחד שמציג מפה של אזור מטה בנימין ועליה שתי שכבות:

1. **מגבלות קבועות** — אזורים אסורים, מוגבלים ומסוכנים לטיסה, מתוך פמ"ת פרק א-17 (נספחים ב' ו-ג').
2. **מגבלות זמניות** — נוטאמים פעילים של מרחב תל אביב (LLLL), מתעדכנים אוטומטית כל שעה.

נכנסים לאתר ביוזמה, כשרוצים לדעת מה המצב. אין התראות, אין מנוי, אין הרשמה.

---

## אזהרה

> **מידע זה אינו מיועד לשימוש מבצעי. אינו מחליף תדריך רשמי או תיאום מול הגורמים המוסמכים.**

זה לא נוסח משפטי לעיטור. הכלי מסתמך על מקור צד־שלישי לא רשמי, ופעילות מקומית
בגובה נמוך לרוב אינה מופצת בערוץ הנוטאמים הבינלאומי כלל.

**היעדר נוטאם באתר אינו ראיה להיעדר מגבלה.**

## איך זה עובד

```
GitHub Actions (cron, כל שעה)
        ↓
  scripts/fetch_notams.py  — משיכה + פרסור
        ↓
  data/notams.json  ←  commit ל-repo
        ↓
GitHub Pages: index.html קורא JSON סטטי
```

הדף **לא** פונה למקור חיצוני בזמן טעינה — מקורות הנוטאמים חוסמים CORS.
המחיר הוא עיכוב של עד שעה בין פרסום נוטאם להופעתו באתר.

## מקורות הנוטאמים

הסקריפט מושך מכל המקורות ומאחד, כדי שנפילה של אתר אחד לא תרוקן את הדף.
מקור שדורש אישורים ולא הוגדר מדלג על עצמו בהודעה ברורה, ואינו נחשב ככשל.

### נדרשת הרשמה חינמית לאחד מהמקורות

זו הפעולה שחוסמת את שכבת הנוטאמים. כל המקורות **ללא** הרשמה נבדקו מול
הרשת האמיתית ואינם שמישים:

| מקור | מצב |
|------|-----|
| `notams.online` | הדף מחזיר HTML ריק. ה-endpoint שלו, `api/notams.php`, מחזיר מטען **מעורפל** שמפוענח ב-`notam-parser.js` שלהם. זו הגנה מכוונת מפני גרידה, ואנחנו לא עוקפים אותה. |
| `notams.faa.gov` (DINS) | 403 לכל בקשה שאינה דפדפן. |
| `notaminfo.com` | 404. |

שני מקורות עובדים, ושניהם דורשים הרשמה חינמית:

**FAA NOTAM API** (מומלץ — רשמי ויציב)

1. הירשמו ב-<https://api.faa.gov/s/> וקבלו `client_id` ו-`client_secret`.
2. Settings → Secrets and variables → Actions → New repository secret:
   * `FAA_CLIENT_ID`
   * `FAA_CLIENT_SECRET`

**autorouter**

1. הירשמו ב-<https://www.autorouter.aero/> וקבלו אישורי OAuth2.
2. הוסיפו כסודות: `AUTOROUTER_CLIENT_ID`, `AUTOROUTER_CLIENT_SECRET`.

מספיק אחד מהשניים. אם שניהם מוגדרים — התוצאות מאוחדות, וכפילויות
מטופלות לפי מזהה הנוטאם.

**עד שיוגדר אישור, הדף מציג אזהרה שהנתונים אינם עדכניים** ואינו מתיימר
להראות "0 נוטאמים פעילים".

נמשכים ה-FIR `LLLL` וגם שדות התעופה `LLBG`, `LLHA`, `LLIB`, `LLRD`, `LLHZ` —
נוטאם ברמת שדה לפעמים כולל הגבלה מקומית שלא עולה לרמת ה-FIR.

**אין סינון תוכן.** כל מה שהמקור החזיר מוצג. הנפח קטן (סדר גודל של 12 פעילים),
ומגבלה חריגה בגובה נמוך היא בדיוק מה שמחפשים — מסנן עלול לבלוע אותה. מה שיש
זה סימון ויזואלי: נוטאם שרצפתו מתחת ל-3,000 רגל מסומן בצבע נפרד, ונוטאמים
מנהלתיים (`CHECKLIST`, `TRIGGER NOTAM`) מתויגים ויורדים לתחתית הרשימה — אך
נשארים גלויים.

### עמידות

אם כל המקורות נכשלים, `notams.json` הקיים **לא נדרס**. במקום זה:

* `stale` נקבע ל-`true`
* `last_error` מקבל את השגיאות
* `last_success` נשאר על הזמן האחרון שהצליח

הדף מציג את הנתונים הישנים עם אזהרה אדומה בולטת על גילם. נתון ישן עם חותמת
זמן כנה עדיף על דף ריק.

## פרסור שורת Q

הלב הטכני. שורת Q נראית כך:

```
Q) LLLL/QRTCA/IV/NBO/W/000/999/3155N03518E010
```

שמונה שדות מופרדים בלוכסן: FIR, קוד Q, תעבורה, מטרה, היקף, גובה תחתון,
גובה עליון, מיקום+רדיוס. שדה המיקום הוא `DDMM[NS]DDDMM[EW]RRR` — בדוגמה:
31°55'N, 035°18'E, רדיוס 10 מייל ימי.

מקרי קצה שמטופלים במפורש:

| מקרה | טיפול |
|------|--------|
| רדיוס `999` | כל ה-FIR. **לא** מצויר עיגול — מוצג כתג "חל על כל המרחב" ברשימה. |
| גבהים `000/999` | "ללא הגבלת גובה", לא 0 עד 99,900 רגל. |
| שורת Q חסרה או פגומה | הרשומה נשמרת עם `geo: null` ומופיעה ברשימה בלי סמן על המפה. |
| `PERM` בשדה סיום | תוקף קבוע, לא תאריך. |
| `EST` אחרי תאריך | מסומן כמשוער. |
| `NOTAMR` / `NOTAMC` | הנוטאם שהוחלף או בוטל מוסר, כך שלא יוצג פעמיים. |
| פריטי `F)`/`G)` | מדויקים יותר משורת Q וגוברים עליה בקביעת רצפת הגובה. |

הרצת הבדיקות:

```bash
python3 -m unittest discover -s scripts -p 'test_*.py' -v
```

## שכבת הפמ"ת

**זהו הנתון החשוב יותר מבין השניים.** הוא מדויק, יציב ובשליטה מלאה — שכבת
הנוטאמים היא תוספת מעליו.

מקור: `https://www.gov.il/BlobFolder/guide/aip/he/aip_א'-17.pdf`
נספח ב' (אסור/מוגבל/מסוכן) ונספח ג' (אסור לכטב"ם — הרלוונטי ביותר לרחפנים).

החילוץ מוגבל לתיבה **31.7–32.1°N, 35.0–35.4°E**. כל הארץ תהפוך את המפה
לבלתי קריאה.

### gov.il חוסם הורדה אוטומטית

זה נבדק מול הרשת האמיתית מ-GitHub Actions:

| ניסיון | תוצאה |
|--------|-------|
| `BlobFolder/guide/aip/he/aip_א'-17.pdf` (שתי צורות קידוד) | **404** |
| `gov.il/he/pages/aip` | **403** |
| `gov.il/he/departments/guides/aip` | **403** |

הכתובת עצמה תקפה בדפדפן — האתר פשוט חוסם לקוחות שאינם דפדפן ו/או כתובות
IP של מרכזי נתונים. כותרות דפדפן לא הספיקו.

**לכן ה-PDF צריך להגיע ידנית.** זה עולה בקנה אחד עם המפרט, שהגדיר את שכבת
הפמ"ת כעבודה חד־פעמית וידנית ברובה.

### הרצה

1. הורידו את פרק א-17 מ-<https://www.gov.il/he/pages/aip> בדפדפן.
2. שמרו אותו כ-`data/aip-a17.pdf` ועשו לו קומיט. הסקריפט מזהה אותו לבד
   ומעדיף אותו על הורדה מהרשת.
3. Actions → **בניית שכבת הפמ"ת** → `mode: dump` — מדפיס את טקסט ה-PDF
   ליומן, לאיתור עמודי נספחים ב' ו-ג'.
4. אותו workflow עם `mode: build` ו-`pages` של הנספחים — מחלץ, ממיר
   ל-GeoJSON ועושה קומיט.

אפשר גם להצביע על כתובת אחרת דרך הקלט `url` ב-workflow.

מקומית:

```bash
pip install -r requirements.txt
python3 scripts/build_aip_geojson.py --pdf data/aip-a17.pdf --dump-text --pages 40-60
python3 scripts/build_aip_geojson.py --pdf data/aip-a17.pdf --pages 40-60
```

**הסקריפט שמרני בכוונה.** בלוק שלא הניב לפחות שלוש נקודות או הגדרת עיגול
מדווח כאזהרה ו**מדולג** — הוא לא מנוחש. אזור מגבלה שגוי מסוכן יותר מאזור חסר.
כל עוד השכבה ריקה, הדף מציג על כך אזהרה מפורשת בראשו.

## מגבלות תפעוליות שחשוב להכיר

* **ה-repo חייב להיות ציבורי.** ב-repo ציבורי דקות Actions הן חינם ובלתי
  מוגבלות. ב-repo פרטי המכסה היא 2,000 דקות בחודש **לכל החשבון** — הרצה שעתית
  תשרוף אותה ותפגע בפרויקטים אחרים.

* **cron מושבת אחרי 60 יום ללא פעילות.** ב-repo ציבורי חינמי GitHub משבית
  אוטומטית תזמוני cron אם לא הייתה פעילות ב-repo במשך 60 יום. הקומיטים
  השעתיים של הסקריפט עצמם נחשבים פעילות, כך שבפועל זה לא אמור לקרות — אבל
  אם המשיכה תיכשל לאורך זמן ולא ייווצרו קומיטים, התזמון ייעצר בשקט. שווה
  לבדוק את חותמת הזמן בראש האתר מדי פעם.

* **עיכוב של עד שעה** בין פרסום נוטאם להופעתו באתר. זה מובנה בארכיטקטורה.

* **הפמ"ת מתעדכן במחזורי AIRAC** (כל 28 יום). שכבת המגבלות הקבועות לא
  מתעדכנת לבד — צריך להריץ מחדש את `build-aip.yml` אחרי עדכון.
